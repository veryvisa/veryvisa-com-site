夫妻怎样叠加

FHSA 与 HBP 的额度都按个人计算，夫妻双方各自符合首次购房条件的，可以各自使用。一方近年住在另一方拥有的房子里，会影响首购资格；两项账户的回看规则要分别核对。

知识卡

首次购房的三项安排

两项联邦账户，一项省级豁免

  1. FHSA：存入抵税，提款免税
  2. HBP：从 RRSP 提款，日后还回
  3. BC 首购豁免：减免产权转让税
  4. 联邦首购抵免：报税时申请

先看：每一项都有自己的首购定义，先逐项核对资格。

易漏：HBP 的钱要还，FHSA 的合资格提款不用还。

下一步：夫妻各自的资格，看下一张卡。

带走：能叠加，前提是每一项单独达标。

知识卡

夫妻分别核对

额度按人计算，资格互相影响

  1. 各自是否首次购房
  2. 各自是否开有 FHSA
  3. 各自 RRSP 余额能否支持 HBP
  4. 房屋登记在谁名下

先看：先看过去几年两人住过的房子归谁所有。

易漏：配偶名下的自住房，也会让另一方失去首购资格。

下一步：物业与产权登记的安排，请律师与地产经纪确认。

带走：夫妻两人，资格要分开看。

常见情形

新移民夫妇，在国内有过自住房。BC 首购豁免看的是过去在任何地方是否拥有过主要住所，国内的房子也算在内；FHSA 与 HBP 看的是近几年是否住在自己或配偶拥有的房子里，回看期内没有，就不受影响。
一方已开 FHSA，另一方还没有。FHSA 的额度从开户那一年才开始累积，没开户的一方没有额度；打算买房的，早些开户可以多积累额度。
RRSP 里的钱不多，FHSA 已经存满。可以先用 FHSA 的合资格提款，HBP 按 RRSP 的实际余额提取；两笔钱都要在各自规定的期限内满足条件。
